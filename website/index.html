What is Firefly LM

不是训练基础模型，是微调和对齐它

从零训练一个 7B 模型需要数千张 H100、数千万费用——这不是开源社区能做的事。
萤火虫选择另一条路：基于已有的最强开源底座（Qwen3、Llama3.1），通过联邦学习持续微调和对齐，让每一次志愿贡献都能积累、都能被验证。

🔥

联邦学习聚合

你的 LoRA 权重片段不离开你的机器。Firefly 调度中心聚合后产生更强的全局模型——贡献可验证，结果公开。

💰

零门槛参与

有 GPU 就能参与。支持 NVIDIA / AMD / Apple Silicon。最小 6GB 显存即可领取轻量任务。客户端全自动。

📊

贡献值可追溯

每一次领取、提交、聚合都有链上（或等效）记录。贡献值公开可查，永久存档在 GitHub。

🔒

OpenRAIL-M 许可

聚合 LoRA 权重采用 OpenRAIL-M 许可证：可商用、禁止武器化、禁止未经同意的监控。

无中央控制

底座模型权重不归属于任何单一实体。最终移交开放原子基金会（v1.0 后申请加入）。

How It Works

参与只需 4 步

1

下载客户端

从 GitHub Releases 下载 firefly-client，一行命令安装。支持 Windows / macOS / Linux。最小显存要求 6GB。

2

注册节点，领取任务

运行 firefly-cli node register 注册算力节点。系统自动分配当前等待中的训练任务，下载对应的微调数据片段。

3

本地训练，上传权重

客户端自动启动 LoRA 微调（QLoRA，4-bit 量化）。完成后自动打包、上传。你随时可以 firefly-cli status 查看进度。

4

贡献值到账，等待聚合

提交成功后，贡献值立即入账。当同一批次累积 ≥ 3 份提交，Firefly 自动触发 FedAvg 聚合，生成更强的全局检查点。
