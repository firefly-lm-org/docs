# 商标检索截图存档

本目录存放萤火虫大模型（Firefly LM）在中美商标数据库的检索截图，作为 VALUATION_GATES #6「商标查询记录存档」的证据。

## 存放结构

- `2026-07-25/` — 中国商标网（wcjs.sbj.cnipa.gov.cn · 商标综合查询，类别 9 / 42）
- `2026-07-25-uspto/` — USPTO（tmsearch.uspto.gov · Basic Word Mark Search，Registered + Pending）

## 要求

- 每个查询词（Firefly LM / 萤火虫 / 萤火虫大模型，类别 9 与 42）至少一张截图
- 截图需包含查询条件与"无记录 / 有冲突"结果页
- 截图比文字结论更有法律效力，开放原子引入期与正式商标申请时作为"已尽检索义务"的证据
- 检索结果同步回填 `docs/TRADEMARK_SEARCH.md` 的预检记录表

> 截图由项目维护者手动上传（数据库需验证码 / 交互，无法自动化）。
